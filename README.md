# Лабораторная работа №5, вариант 14: «Палитра цветов»

## Демо

https://tay47k.github.io/932402.Bayramov.Zaur.lab5/

## Описание

Страница «Палитра цветов» для темы «Дизайнер и визуализатор». Пользователь собирает палитру из цветовых плиток с названиями. Состояние сохраняется в `localStorage` и восстанавливается после перезагрузки страницы.

## Структура

- `index.html` — разметка страницы
- `lab5.css` — оформление, светлая и тёмная темы
- `lab5.js` — логика

## Что реализовано

**Работа с DOM**
- Поиск элементов: `getElementById`
- Создание плиток через `createElement`, сборка через `appendChild`
- Изменение содержимого и стилей: `textContent`, `style.backgroundColor`, `className`, `classList`, атрибут `hidden`
- Обработчики событий `click` (`addEventListener`) и `DOMContentLoaded`

**Функции страницы**
- **Добавить цвет:** `prompt` запрашивает HEX-код (проверка регулярным выражением `#RRGGBB`) и название
- **Удалить цвет:** кнопка на каждой плитке, с анимацией удаления
- **Очистить палитру:** с подтверждением через `confirm`
- **Скрыть/показать палитру:** кнопка меняет текст в зависимости от состояния
- **Переключение темы:** светлая и тёмная, через атрибут `data-theme` на `<html>` и CSS-переменные
- **Счётчик цветов** и подсказка «Палитра пуста»
- **Статусные сообщения** (исчезают через 3 секунды)

**localStorage**
Сохраняются и восстанавливаются при загрузке:
- массив цветов (`designerPalette`, формат JSON)
- выбранная тема (`paletteTheme`)
- видимость палитры (`isPaletteHidden`)

**Обработка ошибок**
- Отмена ввода в `prompt` и неверный HEX-код не добавляют цвет
- Проверка наличия ключевых элементов DOM

## Запуск

1. Откройте `index.html` в браузере (все файлы в одной папке) или перейдите по ссылке из раздела «Демо».
2. Нажмите «Добавить цвет» и введите HEX-код, например `#FF5733`, и название.
3. Перезагрузите страницу: цвета, тема и видимость палитры сохранятся.
4. Данные можно посмотреть в DevTools (F12): вкладка Application → Local Storage.

Шрифты (Fraunces, Space Mono) подключаются с Google Fonts, нужен интернет.
